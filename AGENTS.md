# Работа с сайтом WoodMart

## Файлы темы

- Родительская тема WoodMart лежит в корне репозитория. Используй её код только для чтения и изучения. Запрещено добавлять, редактировать, удалять, перемещать, переименовывать или заменять любые файлы родительской темы, включая корневые `style.css`, `functions.php`, шаблоны и ресурсы.
- Все файловые правки темы делай исключительно в `woodmart-child/`. Для переопределений используй механизмы дочерней темы WordPress и WooCommerce, включая хуки и поддерживаемые переопределения шаблонов.
- Перед коммитом проверь `git diff --name-status` и `git diff --cached --name-status`. Для задачи по теме все внесённые тобой добавления, правки, удаления и переименования должны быть внутри `woodmart-child/`.
- При записи через GitHub Git Data API используй дерево текущего коммита целевой ветки как `base_tree`. Перед обновлением ветки проверь список изменений. При обновлении ветки параллельно перечитай её состояние и перенеси свои правки поверх актуальных файлов. Запрещено заменять дерево репозитория деревом, содержащим только изменённые файлы.

## WordPress Bridge и Elementor

- Для страниц, медиатеки, ACF и SEO используй `codex/scripts/wp`. Перед первой операцией проверь `health`, `site` и `schema`.
- Для существующего блока Elementor используй `elementor-get ID`, найди ID элемента и его параметры, затем используй `elementor-update ID payload.json`. После записи перечитай документ и проверь страницу.
- Проверь адрес сайта перед записью. На опубликованной странице сохранение Elementor применяется сразу.
- Храни учетные данные в переменных окружения или локальном `codex/config/.env`. При конфликте версии перечитай документ перед подготовкой нового запроса.
- Сохраняй клиент Bridge в `codex/` и плагин Elementor в `plugins/codex-elementor-bridge/`. Эти файлы обслуживают интеграцию и меняются только в задачах по самой интеграции.
