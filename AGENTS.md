# Работа с сайтом WoodMart

- Для страниц, медиатеки, ACF и SEO используй `codex/scripts/wp`. Перед первой операцией проверь `health`, `site` и `schema`.
- Для существующего блока Elementor используй `elementor-get ID`, найди ID элемента и его параметры, затем используй `elementor-update ID payload.json`. После записи перечитай документ и проверь страницу.
- Для правок PHP, CSS, JS и шаблонов используй файлы дочерней темы, когда они появятся в репозитории.
- Проверь адрес сайта перед записью. На опубликованной странице сохранение Elementor применяется сразу.
- Храни учетные данные в переменных окружения или локальном `codex/config/.env`. При конфликте версии перечитай документ перед подготовкой нового запроса.
